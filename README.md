# ReelTara

**Watch Free. Discover More.**

ReelTara is a mobile-first movie discovery app for India and the Philippines.

Core product:
- Free legal movies that can be watched inside the app.
- Hot/trending movies with trailers.
- "Where to Watch" buttons that open legal streaming providers.
- Favorites / My List.
- Premium-ready architecture for ad-free and advanced features.

Current phase: UI foundation with mock/local data only.

## Run

```bash
npm install
npm run dev
```

## Stack

- React
- TypeScript
- Vite
- Mobile-first CSS
